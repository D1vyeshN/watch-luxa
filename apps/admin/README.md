# LUXE Admin Dashboard

Admin panel for LUXE Watch Store built with Next.js 16, Refine v5, and Ant Design v5.

## Tech Stack

- **Framework:** Next.js 16
- **Admin Framework:** Refine v5
- **UI Library:** Ant Design v5
- **State Management:** Redux Toolkit
- **Charts:** Recharts
- **Date Handling:** dayjs
- **Styling:** Tailwind CSS v4

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```

## Development

The admin dashboard will run on `http://localhost:3001` (configured to avoid conflict with the web app).
